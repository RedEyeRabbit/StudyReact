Model solution for SkillBadge & SkillList / SkillBadge와 SkillList 모범 답안
🏠 Home / 홈 › Day 2 Lesson / 학습 › Answer / 답안

Explanation

SkillBadge({ label }) destructures the label prop straight out of the function's parameter and renders it. SkillList owns the skills array and is responsible for turning each string into a <SkillBadge> element via .map(), passing label={skill} and a unique key. Notice SkillBadge itself doesn't know it's being rendered in a list — that's the point of props: each component only cares about the data it receives.

설명

SkillBadge({ label })는 함수 매개변수에서 바로 label prop을 구조분해해서 렌더링합니다. SkillList는 skills 배열을 가지고 있으며, .map()으로 각 문자열을 <SkillBadge> 엘리먼트로 변환하는 역할을 담당합니다 — label={skill}과 고유한 key를 전달합니다. SkillBadge 자신은 자기가 목록 안에서 렌더링되는지 전혀 알지 못한다는 점에 주목하세요 — 이것이 props의 핵심입니다: 각 컴포넌트는 자신이 전달받은 데이터에만 신경 씁니다.

Self-check

  • Did SkillBadge receive its data only through props (no hardcoded text)?
  • Does every <SkillBadge> in the list have a unique key?
  • Could you reuse SkillBadge somewhere else with a different label?

스스로 점검하기

  • SkillBadge가 하드코딩된 텍스트 없이 props로만 데이터를 받았나요?
  • 목록의 모든 <SkillBadge>에 고유한 key가 있나요?
  • SkillBadge를 다른 label로 다른 곳에서도 재사용할 수 있나요?
