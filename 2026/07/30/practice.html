Task

Complete two components in the editor below:

  1. SkillBadge — takes a label prop and renders it inside a styled <span>.
  2. SkillList — takes a skills array prop and renders one <SkillBadge> per skill.

Look for the {/* TODO */} comments in the editor.

과제

아래 에디터에서 두 컴포넌트를 완성하세요:

  1. SkillBadge — label prop을 받아 스타일이 적용된 <span> 안에 렌더링.
  2. SkillList — skills 배열 prop을 받아 각 스킬마다 <SkillBadge>를 하나씩 렌더링.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

Destructure the prop directly in the function signature: function SkillBadge({ label }) { ... }. When mapping skills, give each <SkillBadge> a unique key.

힌트

함수 시그니처에서 바로 prop을 구조분해하세요: function SkillBadge({ label }) { ... }. skills를 map할 때 각 <SkillBadge>에 고유한 key를 지정하세요.
