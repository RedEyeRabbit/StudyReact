Day 2 — 초급 (Beginner)

Components & Props / 컴포넌트와 Props
🏠 Home / 홈 › Beginner / 초급 › Day 2

Goal (30–40 min): Understand what components and props are, and build reusable components that take data via props.

목표 (30~40분): 컴포넌트와 props가 무엇인지 이해하고, props로 데이터를 전달받는 재사용 가능한 컴포넌트를 만듭니다.

English

1. What is a component?
A React component is just a JavaScript function that returns JSX. Component names must start with a capital letter (PascalCase) so React can tell them apart from regular HTML tags.

2. Reusability
Once defined, a component can be rendered as many times as you like, like <Greeting /><Greeting /> — each render is an independent instance.

3. Props
Props are how a parent passes data into a child component. They arrive as a single object argument and are read-only — a component must never modify its own props.

한글

1. 컴포넌트란?
React 컴포넌트는 JSX를 반환하는 JavaScript 함수일 뿐입니다. 일반 HTML 태그와 구분하기 위해 컴포넌트 이름은 반드시 대문자로 시작(PascalCase)해야 합니다.

2. 재사용성
한 번 정의한 컴포넌트는 <Greeting /><Greeting />처럼 원하는 만큼 여러 번 렌더링할 수 있으며, 각 렌더링은 독립적인 인스턴스입니다.

3. Props
Props는 부모가 자식 컴포넌트에 데이터를 전달하는 방법입니다. 하나의 객체 인자로 전달되며, 읽기 전용입니다 — 컴포넌트는 자신이 받은 props를 절대 수정하면 안 됩니다.

Key patterns

  • Destructure props in the function signature: function Greeting({ name }) { ... }
  • Pass props like HTML attributes: <Greeting name="React" />
  • props.children holds whatever is nested between a component's opening/closing tags.
  • Compose small components into bigger ones instead of writing one giant component.

핵심 패턴

  • 함수 시그니처에서 props를 구조분해: function Greeting({ name }) { ... }
  • HTML 속성처럼 props 전달: <Greeting name="React" />
  • props.children은 컴포넌트의 여는 태그와 닫는 태그 사이에 중첩된 내용을 담습니다.
  • 거대한 컴포넌트 하나 대신, 작은 컴포넌트들을 조합해서 만드세요.
