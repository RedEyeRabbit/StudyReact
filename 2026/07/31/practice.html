Build a Counter with useState / useState로 카운터 만들기
🏠 Home / 홈 › Day 3 Lesson / 학습 › Practice / 실습

Task

Complete the Counter component below so it has:

  1. A button that increases the count by 1.
  2. A button that decreases the count by 1.
  3. A button that resets the count back to 0.

Look for the {/* TODO */} comments in the editor.

과제

아래 Counter 컴포넌트를 완성해서 다음을 만드세요:

  1. 카운트를 1 증가시키는 버튼.
  2. 카운트를 1 감소시키는 버튼.
  3. 카운트를 0으로 초기화하는 버튼.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

Use the setter function to update state — never mutate the state variable directly. For the reset button, call the setter with the literal value 0.

힌트

state를 바꿀 때는 항상 setter 함수를 사용하세요 — state 변수를 직접 변경하면 안 됩니다. 초기화 버튼은 setter를 0 값으로 호출하면 됩니다.
