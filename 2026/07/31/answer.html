Model solution for the Counter / 카운터 모범 답안
🏠 Home / 홈 › Day 3 Lesson / 학습 › Answer / 답안

Explanation

All three buttons call setCount — React re-renders the component with the new value every time it's called. The +1 and -1 buttons use the current count to compute the next value; the reset button just passes the literal 0. None of them ever write to count directly.

설명

세 버튼 모두 setCount를 호출합니다 — React는 호출될 때마다 새 값으로 컴포넌트를 다시 렌더링합니다. +1과 -1 버튼은 현재 count 값을 이용해 다음 값을 계산하고, 초기화 버튼은 그냥 0을 전달합니다. 셋 다 count에 직접 값을 대입하지 않습니다.

Live solution / 실시간 정답 코드

Self-check

  • Did every button call the setter (not mutate count directly)?
  • Do +1 / -1 use count + 1 / count - 1?
  • Does clicking reset actually bring the count back to 0?

스스로 점검하기

  • 모든 버튼이 (직접 대입이 아니라) setter를 호출했나요?
  • +1 / -1 버튼이 count + 1 / count - 1을 사용하나요?
  • 초기화 버튼을 누르면 실제로 count가 0으로 돌아가나요?
