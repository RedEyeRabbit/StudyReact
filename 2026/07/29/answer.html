Explanation

The heading and paragraph just embed the name and role variables using { }. The skill list uses skills.map((skill, index) => ...) to turn each array item into an <li> element, with a unique key so React can track each item efficiently.

설명

제목과 문단은 { }를 사용해 name, role 변수를 그대로 삽입한 것입니다. 스킬 목록은 skills.map((skill, index) => ...)를 사용해 배열의 각 항목을 <li> 엘리먼트로 변환하며, React가 각 항목을 효율적으로 추적할 수 있도록 고유한 key를 부여합니다.
