Task

Complete the App component below so that it renders:

  1. A heading with your name.
  2. A paragraph with your job/role.
  3. A bullet list of 3 skills, rendered from the skills array using .map().

Look for the {/* TODO */} comments in the editor.

과제

아래 App 컴포넌트를 완성해서 다음을 렌더링하세요:

  1. 이름이 들어간 제목(heading).
  2. 직업/역할이 들어간 문단.
  3. skills 배열을 .map()으로 순회해 렌더링한 스킬 목록 3개.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

When rendering a list with .map(), always add a unique key prop to each item, e.g. key={`skill-${index}`}.

힌트

.map()으로 리스트를 렌더링할 때는 항상 각 항목에 고유한 key prop을 지정해야 합니다. 예: key={`skill-${index}`}.
