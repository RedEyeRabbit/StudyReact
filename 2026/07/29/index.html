Goal (30–40 min): Understand what React is, why it's used, and read/write basic JSX.

목표 (30~40분): React가 무엇이고 왜 사용하는지 이해하고, JSX를 읽고 쓸 수 있게 됩니다.

English

1. What is React?
React is a JavaScript library for building user interfaces out of reusable components. Instead of manually updating the DOM, you describe what the UI should look like for a given state, and React figures out how to update the screen efficiently (using a "virtual DOM").

2. Why React?

  • Component-based: UI is split into small, reusable pieces.
  • Declarative: you describe the result, not the step-by-step DOM manipulation.
  • Huge ecosystem and community.

3. JSX basics
JSX lets you write HTML-like syntax inside JavaScript. It compiles down to React.createElement(...) calls.

한글

1. React란?
React는 재사용 가능한 컴포넌트로 사용자 인터페이스를 만드는 JavaScript 라이브러리입니다. DOM을 직접 조작하는 대신, 특정 상태에서 UI가 어떤 모습이어야 하는지를 선언하면 React가 화면을 효율적으로 어떻게 갱신할지 알아서 처리합니다 ("가상 DOM" 사용).

2. 왜 React인가?

  • 컴포넌트 기반: UI를 작고 재사용 가능한 조각으로 분리.
  • 선언적: 결과를 선언할 뿐, DOM 조작 절차를 직접 작성하지 않음.
  • 거대한 생태계와 커뮤니티.

3. JSX 기초
JSX를 사용하면 JavaScript 안에서 HTML과 비슷한 문법을 쓸 수 있습니다. 내부적으로 React.createElement(...) 호출로 컴파일됩니다.

Key JSX rules

  • Return a single root element (or a fragment <>...</>).
  • Use className instead of class.
  • Embed JS expressions with { }.
  • Self-close empty tags: <img />.

JSX 핵심 규칙

  • 루트 엘리먼트는 하나만 반환 (또는 프래그먼트 <>...</> 사용).
  • class 대신 className 사용.
  • { }로 JS 표현식을 삽입.
  • 내용이 없는 태그는 <img />처럼 self-close.
