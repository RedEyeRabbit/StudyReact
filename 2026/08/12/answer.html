Model solution for UserProfile / UserProfile 모범 답안
🏠 Home / 홈 › Day 1 Lesson / 학습 › Answer / 답안

Explanation

load is a normal async function defined inside the effect, so the effect itself stays synchronous (React is happy). After await, the check if (!ignore) makes sure a response from a request that's since been superseded (because userId changed again) never overwrites newer state. The cleanup sets ignore = true right before the next effect run (or on unmount), which is exactly when a previous request would otherwise resolve out of order.

설명

load는 effect 내부에 정의된 평범한 async 함수라서, effect 자체는 동기 함수로 유지됩니다 (React가 원하는 대로). await 이후 if (!ignore) 체크는, 그 사이에 userId가 다시 바뀌어서 이미 대체된 요청의 응답이 더 최신 state를 덮어쓰지 않도록 막아줍니다. cleanup은 다음 effect가 실행되기 직전(또는 언마운트 시)에 ignore = true로 설정하는데, 이는 정확히 이전 요청이 순서가 뒤바뀌어 도착할 수 있는 바로 그 시점입니다.
