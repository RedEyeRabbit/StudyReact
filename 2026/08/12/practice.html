Build UserProfile with useEffect / useEffect로 UserProfile 만들기
🏠 Home / 홈 › Day 1 Lesson / 학습 › Practice / 실습

Task

Complete the effect inside UserProfile so that:

  1. It sets loading to true, then calls fetchUser(userId).
  2. It stores the result in user and sets loading to false — but only if the effect hasn't been cleaned up.
  3. It re-runs whenever userId changes, and guards against stale responses with an ignore flag.

Look for the {/* TODO */} comments in the editor.

과제

UserProfile 안의 effect를 완성해서:

  1. loading을 true로 설정하고 fetchUser(userId)를 호출하도록.
  2. 결과를 user에 저장하고 loading을 false로 설정하도록 — 단, effect가 정리(cleanup)되지 않은 경우에만.
  3. userId가 바뀔 때마다 다시 실행되고, ignore 플래그로 오래된 응답을 방지하도록.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

The effect function itself must stay synchronous — define async function load() { ... } inside it and call load() right after defining it.

힌트

effect 함수 자체는 동기 함수여야 합니다 — 그 안에 async function load() { ... }를 정의하고, 정의한 직후 load()를 호출하세요.
