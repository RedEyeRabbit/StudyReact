Model solution for ShoppingList / ShoppingList 모범 답안
🏠 Home / 홈 › Day 5 Lesson / 학습 › Answer / 답안

Explanation

items.map(item => ...) turns each item into an <li>, keyed by item.id — a value that stays the same for that item no matter how the array is reordered or filtered. The Remove button doesn't touch the DOM directly; it just asks the parent to update state via onRemove(item.id), and React re-renders the list from the new array.

설명

items.map(item => ...)는 각 항목을 <li>로 변환하며, 배열이 어떻게 재정렬/필터링되든 그 항목에 대해 항상 동일하게 유지되는 값인 item.id를 key로 사용합니다. Remove 버튼은 DOM을 직접 건드리지 않고, onRemove(item.id)로 부모에게 state를 갱신해달라고 요청할 뿐이며, React가 새 배열을 기준으로 리스트를 다시 렌더링합니다.

Self-check

  • Does clicking Remove actually remove only that one item?
  • Does handleRemove use .filter() instead of mutating items?
