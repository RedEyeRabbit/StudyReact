Build ShoppingList with Remove / 삭제 가능한 ShoppingList 만들기
🏠 Home / 홈 › Day 5 Lesson / 학습 › Practice / 실습

Task

Complete ShoppingList so it renders one <li> per item, each with:

  1. The item's text.
  2. A stable key — use item.id, not the array index.
  3. A "Remove" button that calls onRemove(item.id).

Look for the {/* TODO */} comment in the editor.

과제

ShoppingList를 완성해서 항목마다 <li> 하나씩 렌더링하세요. 각 항목에는:

  1. 항목의 텍스트.
  2. 안정적인 key — 배열 인덱스가 아니라 item.id를 사용하세요.
  3. onRemove(item.id)를 호출하는 "Remove" 버튼.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

Removing an item is just replacing state with a filtered array: items.filter(item => item.id !== id) — never mutate the array in place.

힌트

항목 삭제는 필터링한 새 배열로 state를 교체하는 것뿐입니다: items.filter(item => item.id !== id) — 배열을 직접 변경하지 마세요.
