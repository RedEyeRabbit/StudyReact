Complete the cart reducer / 장바구니 리듀서 완성하기
🏠 Home / 홈 › Day 4 Lesson / 학습 › Practice / 실습

Task

Complete cartReducer so it handles three action types:

  1. "ADD_ITEM" — append action.item to the cart.
  2. "REMOVE_ITEM" — remove the item whose id matches action.id.
  3. "CLEAR" — empty the cart.

Look for the {/* TODO */} comments in the editor. Remember: never mutate state, always return a new array.

과제

cartReducer를 완성해서 세 가지 액션 타입을 처리하세요:

  1. "ADD_ITEM" — action.item을 장바구니에 추가.
  2. "REMOVE_ITEM" — id가 action.id와 일치하는 항목 제거.
  3. "CLEAR" — 장바구니 비우기.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요. 잊지 마세요: state를 절대 변경하지 말고, 항상 새 배열을 반환하세요.

Hint

This mirrors patterns you already know: ADD_ITEM is a spread (like Beginner Day 6's add-item form), REMOVE_ITEM is a .filter() (like Beginner Day 5).

힌트

이미 알고 있는 패턴들입니다: ADD_ITEM은 spread(초급 6일차의 항목 추가 폼과 동일), REMOVE_ITEM은 .filter()(초급 5일차와 동일)입니다.
