Model solution for cartReducer / cartReducer 모범 답안
🏠 Home / 홈 › Day 4 Lesson / 학습 › Answer / 답안

Explanation

Every branch returns a brand-new array instead of touching state — [...state, action.item] for adding, .filter() for removing, and a fresh [] for clearing. The default case returning state unchanged is a safety net for any action type the reducer doesn't recognize.

설명

모든 분기가 state를 건드리지 않고 완전히 새로운 배열을 반환합니다 — 추가는 [...state, action.item], 제거는 .filter(), 비우기는 새로운 []. default 케이스가 state를 그대로 반환하는 것은 리듀서가 모르는 액션 타입에 대한 안전장치입니다.

Live solution / 실시간 정답 코드

Self-check

  • Does the cart count update correctly after Add / Remove / Clear?
  • Does removing one item leave the others untouched?
  • Does every branch return a new array, never mutate the old one?

스스로 점검하기

  • Add / Remove / Clear 이후 장바구니 개수가 올바르게 갱신되나요?
  • 항목 하나를 제거해도 나머지는 그대로 남아있나요?
  • 모든 분기가 기존 배열을 변경하지 않고 새 배열을 반환하나요?
