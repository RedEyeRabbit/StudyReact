Model solution for ThemeContext / ThemeContext 모범 답안
🏠 Home / 홈 › Day 3 Lesson / 학습 › Answer / 답안

Explanation

ThemeContext is created once, at module level (not inside a component). App is the only component that writes to it, via the Provider's value prop — whatever it passes is what every useContext(ThemeContext) call anywhere inside sees. Toolbar and Page stay completely unaware that theming exists.

설명

ThemeContext는 (컴포넌트 안이 아니라) 모듈 레벨에서 한 번만 생성됩니다. App이 Provider의 value prop을 통해 이 context에 값을 쓰는 유일한 컴포넌트입니다 — 무엇을 전달하든, 내부 어디서든 호출되는 모든 useContext(ThemeContext)가 그 값을 봅니다. Toolbar와 Page는 테마라는 게 존재하는지조차 전혀 모릅니다.
