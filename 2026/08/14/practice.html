Wire up ThemeContext / ThemeContext 연결하기
🏠 Home / 홈 › Day 3 Lesson / 학습 › Practice / 실습

Task

  1. Create ThemeContext with React.createContext("light").
  2. In ThemedButton, read the current theme with useContext.
  3. In App, wrap the tree in ThemeContext.Provider, passing the current theme state as its value.

Look for the {/* TODO */} comments in the editor.

과제

  1. React.createContext("light")로 ThemeContext를 만드세요.
  2. ThemedButton에서 useContext로 현재 테마를 읽으세요.
  3. App에서 트리를 ThemeContext.Provider로 감싸고, 현재 theme state를 value로 전달하세요.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

Toolbar and Page already don't take or forward any theme-related prop — that's the point. Only ThemedButton (the reader) and App (the provider) touch ThemeContext at all.

힌트

Toolbar와 Page는 이미 테마 관련 prop을 받지도, 전달하지도 않습니다 — 그게 핵심입니다. ThemeContext를 건드리는 건 오직 읽는 쪽인 ThemedButton과 제공하는 쪽인 App뿐입니다.
