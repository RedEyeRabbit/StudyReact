Day 3 — 중급 (Intermediate)

Context API / 컨텍스트 API
🏠 Home / 홈 › Intermediate / 중급 › Day 3

Goal (30–40 min): Share a value across many nested components without passing it down as props at every level.

목표 (30~40분): 모든 단계마다 props로 내려주지 않고도, 여러 겹 중첩된 컴포넌트에 값을 공유합니다.

English

1. The prop drilling problem
Beginner Day 7 lifted state to a common parent and passed it down as props. That works great for two or three levels — but if App → Page → Toolbar → ThemedButton all need a theme value, every level in between has to accept and forward a prop it doesn't actually use. That's "prop drilling."

2. Context: three pieces
React.createContext(defaultValue) creates a Context object. <MyContext.Provider value={theme}> makes a value available to everything nested inside it. useContext(MyContext) reads that value from anywhere inside the provider, no matter how deep.

3. When to reach for it
Good for values that many distant components need — theme, current user, locale. Not a replacement for regular props or state — most data should still flow normally.

한글

1. 프롭 드릴링 문제
초급 7일차에서는 state를 공통 부모로 끌어올려 props로 내려줬습니다. 두세 단계 정도는 이걸로 충분하지만, App → Page → Toolbar → ThemedButton 모두가 theme 값이 필요하다면, 중간의 모든 단계가 실제로 쓰지도 않는 prop을 받아서 다시 전달해야 합니다. 이것이 "prop drilling(프롭 드릴링)"입니다.

2. Context: 세 가지 요소
React.createContext(defaultValue)가 Context 객체를 만듭니다. <MyContext.Provider value={theme}>는 그 안에 중첩된 모든 것에 값을 사용할 수 있게 해줍니다. useContext(MyContext)는 provider 안이라면 어디서든, 아무리 깊어도 그 값을 읽습니다.

3. 언제 쓰나
멀리 떨어진 여러 컴포넌트가 필요로 하는 값 — 테마, 현재 사용자, 언어 설정 등에 좋습니다. 일반 props/state를 대체하는 것이 아니라, 대부분의 데이터는 여전히 평범하게 흘러가야 합니다.
