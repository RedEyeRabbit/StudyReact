Model solution for Hover / Hover 모범 답안
🏠 Home / 홈 › Day 3 Lesson / 학습 › Answer / 답안

Explanation

{render(hovering)} is the entire "connection" — on every render, Hover calls whatever function it was given, passing its current hovering value, and drops the returned JSX right into the tree. Swap in a completely different render prop from App and Hover doesn't need to change at all — the hover-tracking logic is fully reusable.

설명

{render(hovering)}가 "연결"의 전부입니다 — 렌더링될 때마다 Hover는 전달받은 함수를 현재 hovering 값으로 호출하고, 반환된 JSX를 트리에 그대로 끼워 넣습니다. App에서 완전히 다른 render prop으로 바꿔도 Hover는 전혀 바뀔 필요가 없습니다 — hover 추적 로직이 완전히 재사용 가능합니다.

Self-check

  • Could you render something completely different (an icon, a color change) just by changing the render prop, without touching Hover?
