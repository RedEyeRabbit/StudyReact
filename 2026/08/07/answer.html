Model solution for Stopwatch / Stopwatch 모범 답안
🏠 Home / 홈 › Day 8 Lesson / 학습 › Answer / 답안

Explanation

Every time running changes, the effect re-runs. Before it does (and when the component unmounts), React calls the returned cleanup function, which clears the previous interval — so toggling Stop/Start never leaves two intervals running at once. Inside the interval, setSeconds(s => s + 1) reads the freshest state instead of the value captured when the effect started.

설명

running이 바뀔 때마다 effect가 다시 실행됩니다. 다시 실행되기 전(그리고 컴포넌트가 언마운트될 때) React는 반환된 cleanup 함수를 호출해서 이전 interval을 정리합니다 — 그래서 Stop/Start를 토글해도 interval이 동시에 두 개 돌아가는 일이 없습니다. interval 안에서 setSeconds(s => s + 1)은 effect가 시작될 때 붙잡아둔 값이 아니라 항상 최신 state를 읽습니다.

Live solution / 실시간 정답 코드

Self-check

  • Does clicking Stop actually stop the count from increasing?
  • Does clicking Start again resume from the same number, without speeding up (which would mean two intervals are running)?
  • Did you use the functional updater s => s + 1?

스스로 점검하기

  • Stop을 누르면 실제로 카운트 증가가 멈추나요?
  • 다시 Start를 누르면 같은 숫자에서 이어지고, (interval이 두 개 도는 것을 의미하는) 속도가 빨라지지는 않나요?
  • 함수형 업데이트 s => s + 1을 사용했나요?
