Build a Stopwatch with useEffect / useEffect로 스톱워치 만들기
🏠 Home / 홈 › Day 8 Lesson / 학습 › Practice / 실습

Task

Complete the effect inside Stopwatch so that:

  1. While running is true, it increases seconds by 1 every 1000ms.
  2. It returns a cleanup function that clears the interval.

Look for the {/* TODO */} comments in the editor.

과제

Stopwatch 안의 effect를 완성해서:

  1. running이 true인 동안 1000ms마다 seconds를 1씩 증가시키도록.
  2. interval을 정리하는 cleanup 함수를 반환하도록.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

Use the functional updater form setSeconds(s => s + 1) instead of setSeconds(seconds + 1) — inside setInterval's callback, seconds would otherwise always be the value from when the effect first ran (a "stale closure").

힌트

setSeconds(seconds + 1) 대신 함수형 업데이트 setSeconds(s => s + 1)을 사용하세요 — setInterval의 콜백 안에서는 그렇지 않으면 seconds가 항상 effect가 처음 실행됐을 때의 값으로 고정됩니다("stale closure").
