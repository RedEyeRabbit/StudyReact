Day 8 — 초급 (Beginner)

useEffect & Side Effects / useEffect와 사이드 이펙트
🏠 Home / 홈 › Beginner / 초급 › Day 8

Goal (30–40 min): Understand what a side effect is, run one with useEffect, and clean it up correctly.

목표 (30~40분): 사이드 이펙트가 무엇인지 이해하고, useEffect로 실행하고, 올바르게 정리(cleanup)합니다.

English

1. What's a side effect?
Anything that reaches "outside" of just computing UI from props/state: timers, subscriptions, manually touching the DOM, logging, changing document.title, fetching data. Rendering itself should stay pure — side effects belong in useEffect.

2. useEffect basics
useEffect(() => { ... }, [deps]) runs the function after the component renders. The dependency array controls when it re-runs: [] = once, after the first render; [x] = whenever x changes; omitted entirely = after every render.

3. Cleanup
If the effect starts something ongoing (an interval, a subscription), return a cleanup function from it. React calls that cleanup before the effect runs again, and when the component unmounts — this is how you stop a timer or unsubscribe.

한글

1. 사이드 이펙트란?
props/state로 UI를 계산하는 것 "바깥"으로 나가는 모든 것: 타이머, 구독(subscription), DOM 직접 조작, 로깅, document.title 변경, 데이터 가져오기(fetch). 렌더링 자체는 순수하게 유지해야 하며, 사이드 이펙트는 useEffect 안에 넣습니다.

2. useEffect 기초
useEffect(() => { ... }, [deps])는 컴포넌트가 렌더링된 후에 함수를 실행합니다. 의존성 배열이 언제 다시 실행할지 결정합니다: [] = 첫 렌더링 후 딱 한 번, [x] = x가 바뀔 때마다, 아예 생략 = 렌더링될 때마다.

3. 정리(Cleanup)
effect가 계속 진행되는 무언가(interval, subscription)를 시작한다면, 그 안에서 cleanup 함수를 반환하세요. React는 effect가 다시 실행되기 전과 컴포넌트가 언마운트될 때 그 cleanup을 호출합니다 — 이것이 타이머를 멈추거나 구독을 해제하는 방법입니다.
