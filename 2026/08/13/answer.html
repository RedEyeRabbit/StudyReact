Model solution for useUser / useUser 모범 답안
🏠 Home / 홈 › Day 2 Lesson / 학습 › Answer / 답안

Explanation

useUser is exactly Day 1's effect, just moved into its own function and returning { user, loading } instead of rendering anything itself. Because it's a plain function that calls useState/useEffect, any component can call useUser(id) and get live, auto-updating data — the fetching logic is now shared, not copy-pasted.

설명

useUser는 1일차의 effect를 그대로 자기만의 함수로 옮기고, 직접 렌더링하는 대신 { user, loading }을 반환하도록 바꾼 것뿐입니다. useState/useEffect를 호출하는 평범한 함수이기 때문에, 어떤 컴포넌트든 useUser(id)를 호출해서 실시간으로 자동 갱신되는 데이터를 얻을 수 있습니다 — fetch 로직이 이제 복사-붙여넣기가 아니라 공유됩니다.
