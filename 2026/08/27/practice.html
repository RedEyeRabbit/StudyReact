Task

  1. Create LazyChart with React.lazy(() => fakeImport(HeavyChart, 1000)).
  2. When show is true, render <LazyChart /> wrapped in <React.Suspense> with a fallback of <p>Loading chart...</p>.

Look for the {/* TODO */} comments in the editor.

과제

  1. React.lazy(() => fakeImport(HeavyChart, 1000))로 LazyChart를 만드세요.
  2. show가 true일 때, <LazyChart />를 <p>Loading chart...</p> fallback을 가진 <React.Suspense>로 감싸서 렌더링하세요.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

The fallback and the "real" component are never shown at the same time — Suspense handles switching between them for you once the import resolves.

힌트

fallback과 "진짜" 컴포넌트는 동시에 보이지 않습니다 — import가 완료되면 Suspense가 알아서 둘 사이를 전환해줍니다.
