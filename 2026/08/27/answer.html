Model solution for lazy loading / 지연 로딩 모범 답안
🏠 Home / 홈 › Day 2 Lesson / 학습 › Answer / 답안

Explanation

React.lazy takes a function that returns a Promise resolving to { default: Component } — exactly what a dynamic import() resolves to, which is why fakeImport mimics that exact shape. LazyChart isn't rendered at all until show becomes true; only then does React call the function and start "loading." Until it resolves, Suspense shows its fallback instead of throwing an error.

설명

React.lazy는 { default: Component }로 resolve되는 Promise를 반환하는 함수를 받습니다 — 이것이 정확히 동적 import()가 resolve되는 모양이며, 그래서 fakeImport가 그 모양을 똑같이 흉내냅니다. show가 true가 되기 전까지는 LazyChart가 아예 렌더링되지 않습니다 — 그때가 되어서야 React가 함수를 호출하고 "로딩"을 시작합니다. resolve될 때까지 Suspense는 에러를 던지는 대신 fallback을 보여줍니다.
