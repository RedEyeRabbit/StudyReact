Day 4 — 고급 (Advanced)

Compound Components / 컴파운드 컴포넌트
🏠 Home / 홈 › Advanced / 고급 › Day 4

Goal (30–40 min): Build a set of components that implicitly share state through Context, letting the caller freely arrange the markup — like <select>/<option>, but for your own components.

목표 (30~40분): Context를 통해 암묵적으로 state를 공유하는 컴포넌트 묶음을 만들어서, 호출하는 쪽이 마크업을 자유롭게 배치할 수 있게 합니다 — <select>/<option>처럼, 여러분 자신의 컴포넌트로.

English

1. The idea
Instead of one big <Tabs items={[...]} /> component configured entirely through props, expose several small components — Tabs.List, Tabs.Tab, Tabs.Panel — that share state behind the scenes and let the caller compose them like regular JSX.

2. Sharing state without prop drilling
The parent Tabs component holds the active-tab state and provides it via Context (Intermediate Day 3). Each child reads or updates that Context — no one manually passes activeIndex down through props.

3. Attaching sub-components
Tabs.List = TabList is just a property assignment — it lets consumers write <Tabs.List> instead of importing four separate names, which visually groups "these belong together."

한글

1. 아이디어
모든 걸 props로 설정하는 하나의 거대한 <Tabs items={[...]} /> 컴포넌트 대신, Tabs.List, Tabs.Tab, Tabs.Panel처럼 여러 개의 작은 컴포넌트를 노출해서, 내부적으로 state를 공유하며 호출하는 쪽이 평범한 JSX처럼 조합할 수 있게 하세요.

2. 프롭 드릴링 없이 state 공유하기
부모 Tabs 컴포넌트가 활성 탭 state를 갖고 있고, Context(중급 3일차)로 제공합니다. 각 자식은 그 Context를 읽거나 갱신할 뿐, 아무도 activeIndex를 props로 손수 내려주지 않습니다.

3. 서브 컴포넌트 붙이기
Tabs.List = TabList는 그냥 프로퍼티 할당입니다 — 덕분에 네 개의 별도 이름을 import하는 대신 <Tabs.List>라고 쓸 수 있어서, "이들이 한 묶음"임을 시각적으로 보여줍니다.
