Model solution for Tabs / Tabs 모범 답안
🏠 Home / 홈 › Day 4 Lesson / 학습 › Answer / 답안

Explanation

Tab and TabPanel never receive activeIndex as a prop — they each independently call useContext(TabsContext) and read whatever Tabs is currently providing. Clicking any Tab updates the shared context value, which re-renders every Tab (to update bolding) and every TabPanel (to show/hide) — all without a single prop passed between siblings.

설명

Tab과 TabPanel은 activeIndex를 prop으로 전혀 받지 않습니다 — 각자 독립적으로 useContext(TabsContext)를 호출해서 Tabs가 현재 제공하는 값을 읽습니다. 아무 Tab이나 클릭하면 공유된 context 값이 갱신되고, 이는 모든 Tab(굵기 갱신)과 모든 TabPanel(표시/숨김)을 다시 렌더링합니다 — 형제 사이에 prop이 하나도 오가지 않고서요.
