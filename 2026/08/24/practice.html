Build useDebounce / useDebounce 만들기

Task

Complete useDebounce(value, delay) so that:

  1. It schedules a timeout that updates the returned value to the latest value, after delay ms.
  2. It clears that timeout in a cleanup function, so only the most recent one ever fires.

UserSearch below already uses it correctly — you just need to make the hook itself work.

Look for the {/* TODO */} comments in the editor.

과제

useDebounce(value, delay)를 완성해서:

  1. delay ms 후에 반환값을 최신 value로 갱신하는 타임아웃을 예약하도록.
  2. cleanup 함수에서 그 타임아웃을 취소해서, 가장 최근 것만 실행되도록.

아래 UserSearch는 이미 이 훅을 올바르게 사용하고 있습니다 — 훅 자체만 동작하게 만들면 됩니다.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.
