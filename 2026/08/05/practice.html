Build AddItemForm / AddItemForm 만들기

Task

Complete AddItemForm so that:

  1. The input is controlled — bound to the text state.
  2. Submitting the form doesn't reload the page.
  3. Submitting calls onAdd(text) only when text isn't empty, then clears the input.

Look for the {/* TODO */} comments in the editor.

과제

AddItemForm을 완성해서:

  1. 입력창이 text state에 연결된 제어 입력이 되도록.
  2. 폼 제출 시 페이지가 새로고침되지 않도록.
  3. 텍스트가 비어있지 않을 때만 onAdd(text)를 호출하고, 입력창을 비우도록.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

An unfilled value prop on an input makes it "uncontrolled" — always pair value with onChange or React will warn you and the field won't update as you type.

힌트

value prop 없이 두면 input이 "비제어" 상태가 됩니다 — value는 항상 onChange와 짝을 이뤄야 하며, 그렇지 않으면 React가 경고를 표시하고 입력해도 값이 바뀌지 않습니다.
