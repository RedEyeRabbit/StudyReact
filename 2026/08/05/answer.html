Model solution for AddItemForm / AddItemForm 모범 답안
🏠 Home / 홈 › Day 6 Lesson / 학습 › Answer / 답안

Explanation

e.preventDefault() stops the browser's default full-page-reload submit behavior. The text.trim() check avoids adding blank items. After calling onAdd(text), setText("") resets the controlled input back to empty — because the input's value is driven by state, clearing the state clears the box on screen too.

설명

e.preventDefault()는 브라우저의 기본 전체-페이지-새로고침 제출 동작을 막습니다. text.trim() 체크는 빈 항목이 추가되는 것을 막아줍니다. onAdd(text) 호출 후 setText("")로 제어 입력을 다시 빈 값으로 되돌립니다 — input의 값이 state로 구동되기 때문에, state를 비우면 화면의 입력창도 함께 비워집니다.

Self-check

  • Does submitting the form leave the page without reloading?
  • Does the input clear itself after adding an item?
  • Does submitting an empty (or whitespace-only) input do nothing?

스스로 점검하기

  • 폼을 제출해도 페이지가 새로고침되지 않나요?
  • 항목을 추가한 뒤 입력창이 자동으로 비워지나요?
  • 빈 값(또는 공백만 있는 값)을 제출하면 아무 일도 안 일어나나요?
