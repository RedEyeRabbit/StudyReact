Day 6 — 초급 (Beginner)

Forms & Controlled Inputs / 폼과 제어 컴포넌트
🏠 Home / 홈 › Beginner / 초급 › Day 6

Goal (30–40 min): Build a controlled text input bound to state, and handle form submission correctly.

목표 (30~40분): state에 연결된 제어(controlled) 텍스트 입력을 만들고, 폼 제출을 올바르게 처리합니다.

English

1. Controlled inputs
React recommends "controlled" inputs: the input's value comes from state, and onChange updates that state on every keystroke. React is the single source of truth for what's in the box, not the DOM.

2. The pattern
const [text, setText] = useState(""), then <input value={text} onChange={e => setText(e.target.value)} />.

3. Handling submit
<form onSubmit={handleSubmit}>, and inside the handler always call e.preventDefault() first — otherwise the browser does a full page reload, which is almost never what you want in a React app.

한글

1. 제어 입력(Controlled input)
React는 "제어" 입력을 권장합니다: input의 value가 state에서 오고, 키를 누를 때마다 onChange가 그 state를 갱신합니다. 입력창에 무엇이 들어있는지에 대한 단일 진실 공급원(source of truth)은 DOM이 아니라 React입니다.

2. 패턴
const [text, setText] = useState("")를 만들고, <input value={text} onChange={e => setText(e.target.value)} />처럼 씁니다.

3. 제출 처리
<form onSubmit={handleSubmit}>를 쓰고, 핸들러 안에서 항상 먼저 e.preventDefault()를 호출하세요 — 안 그러면 브라우저가 페이지를 전체 새로고침해버리는데, React 앱에서는 거의 항상 원치 않는 동작입니다.
