Day 10 — 중급 (Intermediate) 🎓

Mini Project: User Search / 미니 프로젝트: 사용자 검색
🏠 Home / 홈 › Intermediate / 중급 › Day 10 (Capstone)

Goal (30–40 min): Combine everything from Intermediate Days 1–9 into a small debounced user-search app.

목표 (30~40분): 중급 1~9일차에서 배운 모든 것을 작은 디바운스 사용자 검색 앱으로 합칩니다.

English — What this app uses

  • useEffect & fetching (Day 1) — the search effect awaits a mock lookup and guards against stale responses.
  • Custom hooks (Day 2) — the fetch state lives inside useUserSearch, not the component.
  • useReducer-style thinking (Day 4) — { user, loading } are updated together as one coherent state.
  • Refs (Day 5) — the search box auto-focuses on mount.
  • Debouncing (Day 9) — useDebounce stops it from "searching" on every keystroke.
  • Conditional rendering (Beginner Day 4) — hint / searching / not-found / profile card, one at a time.

No new syntax today — just putting nine days of pieces together.

한글 — 이 앱이 사용하는 것들

  • useEffect와 fetch (1일차) — 검색 effect가 모의 조회를 await하고, 오래된 응답을 방지합니다.
  • 커스텀 훅 (2일차) — fetch state가 컴포넌트가 아니라 useUserSearch 안에 있습니다.
  • useReducer식 사고 (4일차) — { user, loading, error }가 하나의 일관된 state로 함께 갱신됩니다.
  • Ref (5일차) — 검색창이 마운트 시 자동으로 포커스됩니다.
  • 디바운싱 (9일차) — useDebounce가 매 키 입력마다 "검색"하지 않도록 막아줍니다.
  • 조건부 렌더링 (초급 4일차) — 안내문구 / 검색중 / 결과없음 / 프로필 카드 중 하나씩만.

오늘은 새로운 문법이 없습니다 — 9일 동안 배운 조각들을 조립할 뿐입니다.
