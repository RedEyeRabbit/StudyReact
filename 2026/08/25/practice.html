Task

Everything below already works except two spots:

  1. In useUserSearch, complete the effect: if there's no query, clear the user and stop; otherwise set loading, await searchUser, and (if not stale) store the result and clear loading.
  2. In UserSearchApp, complete the content logic: pick between the "type a username" hint, "Searching...", "No user found.", and the profile card, based on query, loading, and user.

Look for the {/* TODO */} comments in the editor.

과제

아래 코드는 두 군데만 빼고 이미 다 동작합니다:

  1. useUserSearch의 effect를 완성하세요: query가 없으면 user를 비우고 종료, 아니면 loading을 켜고 searchUser를 await한 뒤(오래된 요청이 아니라면) 결과를 저장하고 loading을 끄세요.
  2. UserSearchApp의 content 로직을 완성하세요: query, loading, user에 따라 "사용자명 입력" 안내문구, "Searching...", "No user found.", 프로필 카드 중 하나를 고르세요.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.
