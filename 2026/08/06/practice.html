Add an ItemCount sibling / ItemCount 형제 컴포넌트 추가하기
🏠 Home / 홈 › Day 7 Lesson / 학습 › Practice / 실습

Task

ShoppingList and AddItemForm are already wired up. Add a third sibling:

  1. Complete ItemCount so it renders "🧺 {count} item(s) in your list".
  2. Render <ItemCount /> inside App, passing the current number of items as the count prop.

Look for the {/* TODO */} comments in the editor.

과제

ShoppingList와 AddItemForm은 이미 연결되어 있습니다. 세 번째 형제를 추가하세요:

  1. ItemCount를 완성해서 "🧺 {count} item(s) in your list"를 렌더링하도록.
  2. App 안에서 <ItemCount />를 렌더링하면서, 현재 항목 개수를 count prop으로 전달하도록.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

ItemCount doesn't need its own state — it just displays a number it's handed. The array's .length is exactly the count App already knows.

힌트

ItemCount는 자기만의 state가 필요 없습니다 — 전달받은 숫자를 보여주기만 하면 됩니다. 배열의 .length가 바로 App이 이미 알고 있는 개수입니다.
