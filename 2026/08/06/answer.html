Model solution for ItemCount / ItemCount 모범 답안
🏠 Home / 홈 › Day 7 Lesson / 학습 › Answer / 답안

Explanation

ItemCount is a "dumb" presentational component — no state of its own, it just renders whatever count it's given. App already tracks items, so it simply passes items.length down. When items changes (add or remove), App re-renders, and ItemCount automatically gets the fresh count — no extra wiring needed, because it was never a separate source of truth in the first place.

설명

ItemCount는 자기만의 state가 없는 "단순 표시(presentational)" 컴포넌트입니다 — 전달받은 count를 그대로 렌더링할 뿐입니다. App이 이미 items를 추적하고 있으므로, 그냥 items.length를 내려주면 됩니다. items가 바뀌면(추가/삭제) App이 다시 렌더링되고, ItemCount는 자동으로 최신 개수를 받습니다 — 애초에 별도의 진실 공급원이 아니었기 때문에 추가 배선이 필요 없습니다.
