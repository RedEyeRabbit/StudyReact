Build ErrorBoundary / ErrorBoundary 만들기
🏠 Home / 홈 › Day 8 Lesson / 학습 › Practice / 실습

Task

Complete the ErrorBoundary class so that:

  1. getDerivedStateFromError returns new state marking that an error happened.
  2. render() shows a fallback message when that state is set, otherwise renders this.props.children normally.

Look for the {/* TODO */} comments in the editor.

과제

ErrorBoundary 클래스를 완성해서:

  1. getDerivedStateFromError가 에러가 발생했음을 표시하는 새 state를 반환하도록.
  2. render()가 그 state가 설정되면 폴백 메시지를 보여주고, 아니면 평소처럼 this.props.children을 렌더링하도록.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

The constructor already sets up this.state = { hasError: false } — your job is just to flip it to true when an error is caught, and branch on it in render().

힌트

생성자에서 이미 this.state = { hasError: false }를 설정해뒀습니다 — 에러가 잡히면 이걸 true로 바꾸고, render()에서 그에 따라 분기하기만 하면 됩니다.
