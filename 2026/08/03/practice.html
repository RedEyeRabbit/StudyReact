Task

Complete two components in the editor below:

  1. LoginStatus — using the ternary operator, render "Welcome back! 👋" if isLoggedIn is true, otherwise "Please log in."
  2. UnreadBadge — using &&, render "🔴 {count} unread" only when count > 0, otherwise render nothing.

Look for the {/* TODO */} comments in the editor.

과제

아래 에디터에서 두 컴포넌트를 완성하세요:

  1. LoginStatus — 삼항 연산자로, isLoggedIn이 true면 "Welcome back! 👋", 아니면 "Please log in."을 렌더링.
  2. UnreadBadge — &&로, count > 0일 때만 "🔴 {count} unread"를 렌더링하고, 아니면 아무것도 렌더링하지 않기.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

Remember the && pitfall from the lesson: make sure the left side of && is a real boolean expression (count > 0), not just the number count itself.

힌트

학습 내용의 && 함정을 기억하세요: && 왼쪽은 숫자 count 자체가 아니라 진짜 boolean 표현식(count > 0)이어야 합니다.
