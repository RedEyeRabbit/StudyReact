3. 논리 AND (&&)
"이걸 렌더링하거나 아무것도 렌더링하지 않기"에 좋습니다: {count > 0 && }. 왼쪽이 falsy면 React는 아무것도 렌더링하지 않습니다.

⚠️ The && pitfall

If the left side is the number 0 (not false), React actually renders the text "0" on screen — 0 is a valid, renderable value, unlike false/null/ undefined. Fix it by making the check explicitly boolean: count > 0 && ... or Boolean(count) && ....

⚠️ &&의 함정

왼쪽 값이 숫자 0이면 (false가 아니라) React가 실제로 화면에 "0"이라는 텍스트를 렌더링합니다 — 0은 false/null/ undefined와 달리 렌더링 가능한 값이기 때문입니다. 조건을 명시적으로 boolean으로 만들어서 해결하세요: count > 0 && ... 또는 Boolean(count) && ....
