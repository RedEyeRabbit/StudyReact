Model solution for LoginStatus & UnreadBadge / LoginStatus와 UnreadBadge 모범 답안
🏠 Home / 홈 › Day 4 Lesson / 학습 › Answer / 답안

Explanation

LoginStatus uses a ternary to pick one of two complete elements — nothing renders that isn't explicitly one branch or the other. UnreadBadge uses &&: the check is written as count > 0 (a real boolean), not bare count, specifically to avoid the "0" pitfall from the lesson — if count is 0, the expression evaluates to false and React renders nothing.

설명

LoginStatus는 삼항 연산자로 완전한 엘리먼트 두 개 중 하나를 고릅니다 — 두 분기 중 하나가 아닌 것은 렌더링되지 않습니다. UnreadBadge는 &&를 사용하며, 학습 내용의 "0" 함정을 피하기 위해 조건을 그냥 count가 아니라 count > 0(진짜 boolean)으로 작성했습니다 — count가 0이면 이 표현식은 false가 되어 React가 아무것도 렌더링하지 않습니다.

Live solution / 실시간 정답 코드

Self-check

  • Does LoginStatus always render exactly one of the two messages?
  • Does UnreadBadge check count > 0, not just count?
  • If you set count to 0, does nothing render (not the text "0")?

스스로 점검하기

  • LoginStatus가 항상 두 메시지 중 정확히 하나만 렌더링하나요?
  • UnreadBadge가 count가 아니라 count > 0을 검사하나요?
  • count를 0으로 바꿨을 때 "0"이라는 텍스트가 아니라 아무것도 안 뜨나요?
