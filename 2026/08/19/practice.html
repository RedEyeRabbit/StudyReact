Task

Right now, typing in the input re-renders ExpensiveList every keystroke — watch the render count climb. Fix it:

  1. Wrap ExpensiveList's definition with React.memo(...).
  2. Wrap items in useMemo so it's the same array reference every render.
  3. Wrap handleSelect in useCallback so it's the same function reference every render.

Look for the {/* TODO */} comments in the editor.

과제

지금은 입력창에 타이핑할 때마다 ExpensiveList가 매번 리렌더링됩니다 — 렌더 횟수가 올라가는 걸 확인해보세요. 고쳐봅시다:

  1. ExpensiveList 정의를 React.memo(...)로 감싸세요.
  2. items를 useMemo로 감싸서 매 렌더링마다 같은 배열 참조가 되도록 하세요.
  3. handleSelect를 useCallback으로 감싸서 매 렌더링마다 같은 함수 참조가 되도록 하세요.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

All three fixes have empty dependency arrays ([]) here, since items and handleSelect don't actually depend on anything that changes.
