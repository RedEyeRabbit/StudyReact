Day 1 — 고급 (Advanced)

Global State Management / 전역 상태 관리
🏠 Home / 홈 › Advanced / 고급 › Day 1

Goal (30–40 min): Share state between components that aren't parent/child at all, using a tiny hand-built store and useSyncExternalStore — the same primitive libraries like Redux and Zustand build on.

목표 (30~40분): 부모/자식 관계가 전혀 아닌 컴포넌트끼리 상태를 공유합니다. 직접 만든 작은 스토어와 useSyncExternalStore를 사용하는데, Redux나 Zustand 같은 라이브러리도 바로 이 원리를 기반으로 만들어졌습니다.

English

1. Beyond Context
Intermediate Day 3's Context still requires a <Provider> somewhere in the tree above every consumer. A "global store" lives completely outside React — any component, anywhere, can read or write it directly.

2. The store: three functions
getState() returns the current value. setState(updater) changes it and notifies everyone listening. subscribe(listener) registers a callback to run on every change, and returns an unsubscribe function.

3. useSyncExternalStore
This built-in hook is React's official way to subscribe a component to something outside React's own state — pass it your store's subscribe and getState, and it re-renders the component whenever the store notifies a change.

한글

1. Context를 넘어서
중급 3일차의 Context는 여전히 모든 소비자보다 위쪽 트리 어딘가에 <Provider>가 있어야 합니다. "전역 스토어"는 React 바깥에 완전히 독립적으로 존재합니다 — 어디에 있는 컴포넌트든 직접 읽고 쓸 수 있습니다.

2. 스토어: 세 함수
getState()는 현재 값을 반환합니다. setState(updater)는 값을 바꾸고 구독 중인 모두에게 알립니다. subscribe(listener)는 값이 바뀔 때마다 실행할 콜백을 등록하고, 구독 해제 함수를 반환합니다.

3. useSyncExternalStore
이 내장 훅은 React 자체의 state가 아닌 외부의 무언가에 컴포넌트를 구독시키는 공식적인 방법입니다 — 스토어의 subscribe와 getState를 전달하면, 스토어가 변경을 알릴 때마다 컴포넌트를 다시 렌더링합니다.

Live example / 실시간 예제

CounterDisplay and CounterButtons are unrelated siblings — no props, no Context — both driven by the same external store.

CounterDisplay와 CounterButtons는 서로 아무 관계도 없는 형제입니다 — props도 Context도 없이, 같은 외부 스토어로 함께 동작합니다.
