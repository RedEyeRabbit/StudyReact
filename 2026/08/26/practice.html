Build createStore & useStore / createStore와 useStore 만들기
🏠 Home / 홈 › Day 1 Lesson / 학습 › Practice / 실습

Task

  1. Complete createStore's setState — apply the updater (function or partial object) and notify every listener.
  2. Complete createStore's subscribe — add the listener to the set, and return a function that removes it.
  3. Complete useStore using React.useSyncExternalStore.

Look for the {/* TODO */} comments in the editor.

과제

  1. createStore의 setState를 완성하세요 — updater(함수 또는 부분 객체)를 적용하고 모든 listener에게 알리세요.
  2. createStore의 subscribe를 완성하세요 — listener를 set에 추가하고, 제거하는 함수를 반환하세요.
  3. React.useSyncExternalStore를 사용해 useStore를 완성하세요.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

useSyncExternalStore(subscribe, getSnapshot) takes exactly your store's subscribe and getState functions — no wrapping needed.

힌트

useSyncExternalStore(subscribe, getSnapshot)는 스토어의 subscribe와 getState 함수를 그대로 받습니다 — 따로 감쌀 필요 없습니다.
