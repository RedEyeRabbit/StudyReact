Model solution for the mini router / 미니 라우터 모범 답안
🏠 Home / 홈 › Day 7 Lesson / 학습 › Answer / 답안

Explanation

navigate(to) returns an event handler (a function that takes e) — that's why it's called as onClick={navigate("/about")} rather than onClick={navigate}. Inside, e.preventDefault() stops the browser's real navigation, and setPath(to) triggers a re-render where routes[path] now points at a different component — which is the entire "router."

설명

navigate(to)는 이벤트 핸들러(즉 e를 받는 함수)를 반환합니다 — 그래서 onClick={navigate}가 아니라 onClick={navigate("/about")}처럼 호출합니다. 내부에서 e.preventDefault()가 브라우저의 실제 이동을 막고, setPath(to)가 리렌더링을 일으켜서 routes[path]가 이제 다른 컴포넌트를 가리키게 됩니다 — 이것이 "라우터"의 전부입니다.
