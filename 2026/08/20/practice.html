Task

Complete the mini router in App so that:

  1. Page is looked up from the routes table using the current path.
  2. Clicking a link calls navigate(to), which prevents the default full-page navigation and updates path.

Look for the {/* TODO */} comments in the editor.

과제

App의 미니 라우터를 완성해서:

  1. 현재 path를 사용해 routes 테이블에서 Page를 찾도록.
  2. 링크를 클릭하면 navigate(to)가 호출되어 기본 전체 페이지 이동을 막고 path를 갱신하도록.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

e.preventDefault() is the same trick from Beginner Day 6's forms — without it, the browser would do a real navigation and throw away all your React state.

힌트

e.preventDefault()는 초급 6일차 폼에서 썼던 것과 같은 트릭입니다 — 이게 없으면 브라우저가 실제로 이동해버려서 React state가 모두 사라집니다.
