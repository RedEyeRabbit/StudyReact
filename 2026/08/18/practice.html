Build SearchInput with refs / ref로 SearchInput 만들기
🏠 Home / 홈 › Day 5 Lesson / 학습 › Practice / 실습

Task

Complete SearchInput so that:

  1. The input is focused automatically when the component mounts.
  2. A label below shows the previous value of the input (before your latest keystroke), tracked with a ref.

Look for the {/* TODO */} comments in the editor.

과제

SearchInput을 완성해서:

  1. 컴포넌트가 마운트될 때 입력창에 자동으로 포커스가 가도록.
  2. 아래 라벨이 (가장 최근 입력 전의) 이전 값을 ref로 추적해서 보여주도록.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

Two separate refs, two separate jobs: one holds the DOM node (for .focus()), the other just holds a string. Neither should be useState.

힌트

서로 다른 두 ref, 서로 다른 두 역할: 하나는 DOM 노드를 담고(.focus()용), 다른 하나는 그냥 문자열을 담습니다. 둘 다 useState여서는 안 됩니다.
