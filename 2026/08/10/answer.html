Model solution for PriorityBadge / PriorityBadge 모범 답안
🏠 Home / 홈 › Day 9 Lesson / 학습 › Answer / 답안

Explanation

colors is a plain object used as a lookup table: colors[level] reads the right color for whichever string level is. That value feeds straight into the style object's background property. This scales better than a chain of if/else once you have more than two or three cases.

설명

colors는 조회 테이블로 쓰이는 평범한 객체입니다: colors[level]은 level이 어떤 문자열이든 그에 맞는 색을 읽어옵니다. 그 값이 그대로 style 객체의 background 프로퍼티로 들어갑니다. 조건이 두세 개를 넘어가면 if/else를 나열하는 것보다 이 방식이 더 잘 확장됩니다.

Self-check

  • Does each badge show a visibly different background color?
  • Did you use className or the style object — never the bare class attribute?
  • Would adding a fourth level ("urgent") only require one new entry in your color mapping?
