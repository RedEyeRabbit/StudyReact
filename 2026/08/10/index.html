Day 9 — 초급 (Beginner)

Styling in React / React에서 스타일링하기
🏠 Home / 홈 › Beginner / 초급 › Day 9

Goal (30–40 min): Apply CSS classes and inline styles in JSX, and build class names conditionally based on state/props.

목표 (30~40분): JSX에서 CSS 클래스와 인라인 스타일을 적용하고, state/props에 따라 조건부로 클래스 이름을 만듭니다.

English

1. className, not class
class is a reserved JS keyword, so JSX uses className instead: <div className="card">. This site's own assets/style.css (the .card, .tag, .filelinks classes you've seen on every page) is a real example.

2. Inline styles
style takes a JS object, not a CSS string, with camelCase property names: style={{ color: "red", fontSize: 14 }}. Numbers default to pixels for most size properties.

3. Conditional class names
Build the class string based on state/props, e.g. by concatenating: className={"btn " + (isActive ? "btn-active" : "")}. For a handful of conditions this is enough — no library required.

한글

1. class가 아니라 className
class는 JS 예약어라서, JSX는 대신 className을 사용합니다: <div className="card">. 이 사이트 자체의 assets/style.css(모든 페이지에서 봐온 .card, .tag, .filelinks 클래스들)가 실제 예시입니다.

2. 인라인 스타일
style은 CSS 문자열이 아니라 JS 객체를 받으며, 프로퍼티 이름은 camelCase입니다: style={{ color: "red", fontSize: 14 }}. 대부분의 크기 프로퍼티에서 숫자는 기본적으로 픽셀 단위입니다.

3. 조건부 클래스 이름
state/props에 따라 클래스 문자열을 만드세요, 예를 들어 문자열을 이어붙여서: className={"btn " + (isActive ? "btn-active" : "")}. 몇 가지 조건 정도는 이걸로 충분합니다 — 별도 라이브러리가 필요 없습니다.
