Build a styled PriorityBadge / 스타일이 적용된 PriorityBadge 만들기
🏠 Home / 홈 › Day 9 Lesson / 학습 › Practice / 실습

Task

Complete PriorityBadge({ level }) so it renders the text of level ("low" / "medium" / "high") with a different background color per level:

  • "low" → gray
  • "medium" → orange
  • "high" → red

Look for the {/* TODO */} comment in the editor. Any way of picking the color per level is fine (if/else, a lookup object, ...).

과제

PriorityBadge({ level })를 완성해서 level("low" / "medium" / "high")의 텍스트를 레벨마다 다른 배경색으로 렌더링하세요:

  • "low" → 회색
  • "medium" → 주황색
  • "high" → 빨간색

에디터 안의 {/* TODO */} 주석 부분을 채워보세요. 레벨별 색을 고르는 방법은 무엇이든 괜찮습니다 (if/else, 조회용 객체 등).

Hint

A lookup object keeps this tidy: { low: "#9e9e9e", medium: "#f57c00", high: "#d32f2f" }, then read the color with colors[level].

힌트

조회용 객체를 쓰면 깔끔합니다: { low: "#9e9e9e", medium: "#f57c00", high: "#d32f2f" }로 만들고, colors[level]로 색을 읽으세요.
