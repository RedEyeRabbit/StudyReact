🏠 Home / 홈 › Day 10 Lesson / 학습 › Answer / 답안

Explanation

onClick={() => onToggle(todo.id)} just forwards the click up to the callback App handed down — TodoItem doesn't know or care how toggling is implemented, only that it should ask for it. In handleToggle, todos.map(t => t.id === id ? { ...t, done: !t.done } : t) builds a brand new array: the matching todo becomes a new object with done flipped (via the spread + override pattern from Day 5's immutable updates), every other todo is passed through unchanged.

설명

onClick={() => onToggle(todo.id)}는 클릭을 App이 내려준 콜백으로 그대로 전달할 뿐입니다 — TodoItem은 토글이 어떻게 구현되는지 몰라도 되고, 그저 요청만 하면 됩니다. handleToggle에서 todos.map(t => t.id === id ? { ...t, done: !t.done } : t)는 완전히 새로운 배열을 만듭니다: 일치하는 할 일은 done이 뒤집힌 새 객체가 되고(spread + 덮어쓰기 패턴), 나머지 할 일은 그대로 통과합니다.
