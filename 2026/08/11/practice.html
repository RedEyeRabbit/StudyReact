Task

Everything below already works except two spots:

  1. In TodoItem, clicking the <span> should call onToggle(todo.id) (it currently does nothing).
  2. In App, handleToggle should flip the done flag of the matching todo, using .map() — don't mutate the array or any todo object directly.

Look for the {/* TODO */} comments in the editor.

과제

아래 코드는 두 군데만 빼고 이미 다 동작합니다:

  1. TodoItem에서 <span>을 클릭하면 onToggle(todo.id)가 호출되어야 합니다 (지금은 아무 일도 안 일어남).
  2. App에서 handleToggle이 .map()을 사용해 해당 할 일의 done 플래그를 뒤집어야 합니다 — 배열이나 할 일 객체를 직접 변경하지 마세요.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.
