Goal (30–40 min): Combine everything from Days 1–9 into one small, complete Todo List app.

목표 (30~40분): 1~9일차에서 배운 모든 것을 하나의 작고 완전한 할 일 목록 앱으로 합칩니다.

English — What this app uses

  • Components & props (Day 2) — TodoItem, TodoList, AddTodoForm are all separate, reusable pieces.
  • State & events (Day 3) — todos lives in App's state; buttons and form submission trigger updates.
  • Conditional rendering / styling (Days 4, 9) — a completed todo gets a strikethrough style based on its done flag.
  • Lists & keys (Day 5) — each todo is keyed by its stable id, never the array index.
  • Forms (Day 6) — AddTodoForm is a controlled input with proper submit handling.
  • Lifting state up (Day 7) — App owns the data; children only get props and callbacks.

No new syntax today — just putting the pieces together.

한글 — 이 앱이 사용하는 것들

  • 컴포넌트와 props (2일차) — TodoItem, TodoList, AddTodoForm은 모두 재사용 가능한 별개 조각입니다.
  • State와 이벤트 (3일차) — todos는 App의 state에 있으며, 버튼과 폼 제출이 갱신을 일으킵니다.
  • 조건부 렌더링/스타일링 (4, 9일차) — 완료된 할 일은 done 플래그에 따라 취소선 스타일이 적용됩니다.
  • 리스트와 key (5일차) — 각 할 일은 배열 인덱스가 아니라 안정적인 id로 key가 지정됩니다.
  • 폼 (6일차) — AddTodoForm은 제출 처리가 올바른 제어 입력입니다.
  • State 끌어올리기 (7일차) — App이 데이터를 소유하고, 자식들은 props와 콜백만 받습니다.

오늘은 새로운 문법이 없습니다 — 배운 조각들을 조립할 뿐입니다.
