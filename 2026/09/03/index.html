Testing with React Testing Library / React Testing Library로 테스트하기
🏠 Home / 홈 › Advanced / 고급 › Day 7

Goal (30–40 min): Write an automated test that interacts with a component the way a user would, using React Testing Library (RTL).

목표 (30~40분): React Testing Library(RTL)로, 사용자가 하는 것과 같은 방식으로 컴포넌트와 상호작용하는 자동화된 테스트를 작성합니다.

English

1. RTL's philosophy
"The more your tests resemble the way your software is used, the more confidence they can give you." RTL doesn't let you reach into a component's internal state or call its functions directly — you render it, then query and interact with it the way a real user (or screen reader) would.

2. The core API
render(<Component />) mounts it into a virtual DOM. screen.getByRole("button", { name: "..." }) finds elements the same way assistive tech does — by accessible role and name, which is exactly what Day 6's ARIA work was building toward. fireEvent.click(el) simulates a real interaction. expect(...).toBeInTheDocument() asserts on the result.

3. This is a real, runnable test
Unlike earlier "browser vs. Node lab" days, there's no browser-CDN version of this — test runners aren't meant to run inside a rendered page. The code below is real; run it for real in Practical Lab with npm test.

한글

1. RTL의 철학
"테스트가 소프트웨어가 실제로 사용되는 방식과 닮을수록, 더 많은 확신을 줄 수 있다." RTL은 컴포넌트의 내부 state에 직접 접근하거나 함수를 직접 호출하게 해주지 않습니다 — 렌더링한 다음, 실제 사용자(또는 스크린 리더)처럼 조회하고 상호작용합니다.

2. 핵심 API
render(<Component />)는 가상 DOM에 마운트합니다. screen.getByRole("button", { name: "..." })는 보조 기술과 똑같은 방식 — 접근성 role과 name — 으로 엘리먼트를 찾는데, 이것이 정확히 6일차 ARIA 작업이 향하던 지점입니다. fireEvent.click(el)은 실제 상호작용을 흉내냅니다. expect(...).toBeInTheDocument()가 결과를 검증합니다.

3. 이건 진짜, 실행 가능한 테스트입니다
앞선 "브라우저 vs. Node Lab" 형식의 날들과 달리, 이건 브라우저 CDN 버전이 없습니다 — 테스트 러너는 렌더링된 페이지 안에서 돌아가도록 만들어진 게 아니니까요. 아래 코드는 진짜입니다 — Practical Lab에서 npm test로 실제로 실행해보세요.

The real test / 실제 테스트 코드

This runs for real via npm test in Practical Lab (id 2026-09-03) — not in this browser page.

이 코드는 Practical Lab(id 2026-09-03)에서 npm test로 실제 실행됩니다 — 이 브라우저 페이지 안에서가 아니라.

import { render, screen, fireEvent } from "@testing-library/react";
import { expect, test } from "vitest";
import LoginButton from "./LoginButton.jsx";

test("toggles between Log in and Log out when clicked", () => {
  render(<LoginButton />);

  expect(screen.getByRole("button", { name: "Log in" })).toBeInTheDocument();

  fireEvent.click(screen.getByRole("button"));

  expect(screen.getByRole("button", { name: "Log out" })).toBeInTheDocument();
});
