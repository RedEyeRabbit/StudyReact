Build an accessible Disclosure / 접근성을 갖춘 Disclosure 만들기
🏠 Home / 홈 › Day 6 Lesson / 학습 › Practice / 실습

Task

Complete Disclosure so that:

  1. The trigger is a real <button> (not a clickable <div>) with aria-expanded reflecting open, and aria-controls pointing at the content's id.
  2. The content <div> has that same id (from React.useId()) and only renders when open is true.

Look for the {/* TODO */} comments in the editor.

과제

Disclosure를 완성해서:

  1. 트리거가 진짜 <button>(클릭 가능한 <div>가 아니라)이고, aria-expanded가 open을 반영하고, aria-controls가 콘텐츠의 id를 가리키도록.
  2. 콘텐츠 <div>가 (React.useId()로 만든) 같은 id를 가지고, open이 true일 때만 렌더링되도록.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

Try tabbing to the button with your keyboard instead of clicking — a real <button> should already respond to Enter/Space with no extra code from you.

힌트

클릭 대신 키보드로 버튼에 Tab을 이용해 포커스를 옮겨보세요 — 진짜 <button>이라면 별도 코드 없이도 Enter/Space에 이미 반응해야 합니다.
