Model solution for withLoading / withLoading 모범 답안
🏠 Home / 홈 › Day 5 Lesson / 학습 › Answer / 답안

Explanation

withLoading never touches UserList itself — it only decides, from the outside, whether UserList gets to render at all this time. <Component {...props} /> forwards everything the wrapped component receives (here, isLoading and users) straight through, so UserList doesn't need to know it's being wrapped at all.

설명

withLoading은 UserList 자체를 전혀 건드리지 않습니다 — 그저 바깥에서, 이번에 UserList가 아예 렌더링될지 여부만 결정할 뿐입니다. <Component {...props} />는 감싸인 컴포넌트가 받는 모든 것(여기서는 isLoading과 users)을 그대로 전달하므로, UserList는 자신이 감싸여 있다는 사실조차 알 필요가 없습니다.

Self-check

  • Does toggling loading switch between the spinner text and the actual list?
  • Does UserList still receive its users prop correctly once loading is false?
  • Could you reuse withLoading on a totally different component (say, a chart) without changing it?

스스로 점검하기

  • 로딩을 토글하면 스피너 텍스트와 실제 리스트 사이가 전환되나요?
  • 로딩이 false가 되면 UserList가 여전히 users prop을 올바르게 받나요?
  • withLoading을 수정하지 않고도 완전히 다른 컴포넌트(예: 차트)에 재사용할 수 있을까요?
