Build withLoading / withLoading 만들기

Task

Complete withLoading(Component) so the component it returns:

  1. Shows <p>⏳ Loading...</p> when props.isLoading is true.
  2. Otherwise renders Component with all of its props forwarded.

Look for the {/* TODO */} comment in the editor.

과제

withLoading(Component)가 반환하는 컴포넌트가:

  1. props.isLoading이 true일 때 <p>⏳ Loading...</p>를 보여주도록.
  2. 아니면 Component를 모든 props와 함께 전달해서 렌더링하도록.

에디터 안의 {/* TODO */} 주석 부분을 채워보세요.

Hint

Spreading props forward is exactly <Component {...props} /> — the same spread syntax you've used on arrays and objects, just on JSX props.

힌트

props를 그대로 전달하는 건 정확히 <Component {...props} />입니다 — 배열/객체에 쓰던 것과 같은 spread 문법을, JSX props에 쓰는 것뿐입니다.
