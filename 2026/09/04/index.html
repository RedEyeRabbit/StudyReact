Goal (30–40 min): Build a real, accessible modal dialog — combining component composition with the accessibility fundamentals from Day 6.

목표 (30~40분): 컴포넌트 조합과 6일차의 접근성 기초를 결합해서, 실제로 접근 가능한 모달 다이얼로그를 만듭니다.

English — What this app uses

  • Accessibility (Day 6) — role="dialog", aria-modal, aria-labelledby.
  • Effects & cleanup (Intermediate Day 8) — Escape-to-close is a keydown listener added on open and removed on close.
  • Refs (Intermediate Day 5) — one ref points at the dialog itself (to focus it), another remembers what was focused before opening (to restore it on close).
  • Conditional rendering (Beginner Day 4) — the modal renders nothing at all while closed.

A real modal needs to work for keyboard and screen-reader users just as well as mouse users — that's what today combines into one component.

한글 — 이 앱이 사용하는 것들

  • 접근성 (6일차) — role="dialog", aria-modal, aria-labelledby.
  • Effect와 cleanup (중급 8일차) — Escape로 닫기는 열릴 때 추가되고 닫힐 때 제거되는 keydown 리스너입니다.
  • Ref (중급 5일차) — 하나는 다이얼로그 자체를 가리켜 포커스를 주고, 다른 하나는 열리기 전에 포커스되어 있던 요소를 기억해뒀다가 닫힐 때 되돌립니다.
  • 조건부 렌더링 (초급 4일차) — 닫혀있는 동안 모달은 아예 아무것도 렌더링하지 않습니다.

진짜 모달은 마우스 사용자만큼이나 키보드/스크린 리더 사용자에게도 잘 동작해야 합니다 — 오늘은 그걸 하나의 컴포넌트로 합칩니다.

Live example — the finished app / 실시간 예제 — 완성된 앱

Open the modal, then try Escape to close it, and notice focus returns to the button that opened it.
