Model solution for the accessible Modal / 접근성을 갖춘 Modal 모범 답안
🏠 Home / 홈 › Day 8 Lesson / 학습 › Answer / 답안

Explanation

document.activeElement captured before moving focus is whatever element the user was on before opening the modal — almost always the button that triggered it. The Escape listener is added to document (not the dialog) so it fires no matter what's focused inside. The cleanup function runs both when isOpen flips back to false and if the component unmounts entirely, so the listener never leaks and focus is never left stranded on a closed dialog.

설명

포커스를 옮기기 전에 캡처한 document.activeElement는 모달을 열기 전 사용자가 있던 요소입니다 — 거의 항상 모달을 트리거한 버튼입니다. Escape 리스너는 (다이얼로그가 아니라) document에 추가되므로, 내부에서 무엇이 포커스되어 있든 상관없이 실행됩니다. cleanup 함수는 isOpen이 다시 false가 될 때와 컴포넌트가 완전히 언마운트될 때 모두 실행되므로, 리스너가 절대 누수되지 않고 포커스가 닫힌 다이얼로그에 갇혀버리는 일도 없습니다.
